## 配置与使用说明

自动接入仅维护本应用的五类生命周期 Hook，修改前备份。不改认证、模型或权限，不自动安装 MCP 或状态栏，不覆盖用户修改的管理项，并遵守客户端禁用策略。0.12.1 的记事板按钮与 Codex 一致，点击后直接配置 MCP 并在页面内反馈，不附带修改 Hook 或状态栏；完整增强仍保留独立确认。

首次自动配置后，需新开 Claude 会话或重载扩展；已有会话不保证热加载。缺少 Node.js 20+ 时，自动生命周期保留只读发现并提供诊断，不将缺少终态的文字回复判为完成。记事板 MCP 使用应用自带的 Electron Node 模式运行。

SDK 新建/恢复不等于向原客户端窗口注入；应用工具约束不等于操作系统沙箱。
