# Agent Pet 使用指南

[返回项目首页](../README.md) · [微信指令指南](WEIXIN_REMOTE_CONTROL.md)

## 下载与启动

在 [GitHub Releases](https://github.com/wy1003/agent-pet/releases) 下载 Windows x64 版本：

| 文件 | 适合谁 |
| --- | --- |
| `Agent-Pet-Setup-<version>-x64.exe` | 日常使用；安装版支持应用内更新 |
| `Agent-Pet-Portable-<version>-x64.exe` | 免安装使用；更新时手动下载新版本 |

运行后，Agent Pet 会自动发现当前 Windows 用户下的 Codex 任务。点击桌宠打开任务列表，通过任务面板或系统托盘进入设置。

设置自动保存在本机，覆盖安装新版本会保留现有设置、微信连接、宠物、音色和通知记录。本文描述当前源码；安装包的功能以对应版本发布说明为准。

## 桌宠与任务收件箱

每次向 Codex 提交的问题对应一项独立任务，可以同时查看不同项目、不同会话的进度。

- 宠物根据工作、等待输入、完成、失败等状态切换动画。
- 任务完成、失败或中断后保留提醒，可以手动确认。
- 在同一会话继续提问时，之前已结束的提醒自动标记为已读，历史仍保留。
- 其他会话和仍在运行的任务不受自动已读影响。

桌宠支持拖动、位置记忆、惯性甩动和屏幕边缘反弹。更换显示器或调整缩放后，应用会尽量将宠物恢复到可见区域。

## 通知与语音

在设置中分别选择需要提醒的任务事件、通知渠道和免打扰时段。

| 渠道 | 功能 |
| --- | --- |
| Windows 系统通知 | 在桌面接收任务提醒 |
| 系统语音 | 使用 Windows 已安装音色播报 |
| GPT-SoVITS | 按需安装本地语音环境，使用自定义模型和参考音频 |
| 个人微信 | 接收任务结果、失败和等待输入提醒 |

GPT-SoVITS 不包含在主安装包中，也不会修改系统 Python、PATH 或 Conda 配置。使用自定义音色时，请导入自己有权使用的模型和参考音频；项目不附带第三方角色音色。

## 微信收发指令

在“设置 → 远程通知”扫码连接微信，按提示完成绑定。开启“发送远程通知”后，可以在手机接收任务提醒；另外开启默认关闭的“指令操作”后，可以从微信继续 Codex 会话或新建任务。

查询会话编号用 `/sessions`，继续会话用 `/S0001 你的要求`。普通聊天消息不会执行任务。电脑需保持联网并运行 Agent Pet。

完整的连接步骤、指令、权限边界、Desktop / SDK 兼容范围和错误处理见 [微信远程指令指南](WEIXIN_REMOTE_CONTROL.md)。

## 自定义宠物

在“设置 → 外观与启动 → 宠物库”中拖入 ZIP，或点击“选择 ZIP”。导入后使用应用管理的副本，原压缩包可以移动或删除。

支持两种格式：

| 格式 | 包内容 |
| --- | --- |
| Codex 原生精灵表 | 根目录包含 `pet.json` 与 `spritesheet.webp` 或 `spritesheet.png`；支持 v1 的 8×9 和 v2 的 8×11 网格 |
| Agent Pet 状态 GIF | 同一英文前缀的状态文件，例如 `my-pet-idle.gif`、`my-pet-running.gif`，可以只提供已有状态 |

导入器会检查目录结构、路径、图片尺寸和动画帧数。宠物库提供下载网站入口；其他来源的格式不兼容时，点击“复制转换说明”，将说明与素材一起交给 AI 转换后再导入。

## 每日工作总结

按项目整理当天完成的任务，支持编辑、复制和重新生成，方便回顾工作内容。

## 隐私与数据

- 采集器只读本机 Codex 任务记录，不直接改写原始会话文件。开启指令操作后，通过 Codex Desktop 或 SDK 提交请求，由 Codex 执行并保存。
- 设置、宠物、音色、日报和通知记录默认保存在本机。
- 微信凭据通过系统安全存储加密，不写入普通设置文件；解除连接时清除。
- 微信通知可选择简略、标准或完整内容级别。
- 远程指令只接受已绑定账号的私聊，经过消息去重、串行队列和高风险指令拦截；需要电脑端审批的操作回到电脑处理。

## 从源码运行

需要 Node.js 20 或更高版本：

```powershell
git clone https://github.com/wy1003/agent-pet.git
cd agent-pet
npm install
npm run companion
```

也可以双击根目录的 `start-agent-pet.cmd`，首次运行会安装依赖并启动应用。

运行自动化测试：

```powershell
npm test
```
