# Agent Pet 使用指南

[返回项目首页](../README.md) · [微信指令指南](WEIXIN_REMOTE_CONTROL.md)

## 下载与启动

在 [GitHub Releases](https://github.com/wy1003/agent-pet/releases) 下载 Windows x64 版本：

| 文件 | 适合谁 |
| --- | --- |
| `Agent-Pet-Setup-<version>-x64.exe` | 日常使用；安装版支持应用内更新 |
| `Agent-Pet-Portable-<version>-x64.exe` | 免安装使用；更新时手动下载新版本 |

运行后，Agent Pet 会自动发现当前 Windows 用户下的 Codex 任务。点击桌宠打开任务列表，通过任务面板或系统托盘进入设置。

设置自动保存在本机，覆盖安装新版本会保留现有设置、微信连接、宠物、音色和通知记录。本文描述当前源码；安装包的功能以对应版本发布说明为准。

设置菜单分为三组：**应用**（通用、智能体与 AI）、**桌面**（宠物、任务与额度、记事板）、**通知**（提醒规则、系统通知、语音播报、远程通知）；参与共建独立放在菜单底部。智能体任务来源与 AI 文本生成在同一页分区管理；记事板的显示、外观、AI 写入和存档集中在“记事板”。通知记录目录位于“系统通知”，免打扰位于“提醒规则”。

## Claude Code 接入与恢复

本节描述 **0.11.3 源码**，不表示对应安装包已经发布。

### 默认自动发现

打开 Agent Pet 后，Codex 与 Claude 同时采集，无需选择来源。Claude 只读 `~/.claude/projects/<项目>/<会话>.jsonl`，尊重启动时的 `CLAUDE_CONFIG_DIR`，不扫描子代理目录。CLI / VS Code 需在该配置根产生本地会话日志。首次只发现最近 24 小时的用户轮次，后续增量跟踪；重启保留已读状态。日志半行写完后再解析，原始日志不变。

默认开启“自动确认 Claude 任务完成”：桌宠自动查找 Node.js 20+，在已有配置目录中备份并维护 SessionStart、UserPromptSubmit、Stop、StopFailure、SessionEnd 五类 Hook；不需要点击安装或填写 Node 路径。仅修改本应用管理项及其记录，不改认证、模型、权限，也不自动安装 MCP/状态栏。配置目录尚不存在、运行时缺失、配置被改写或客户端禁用 Hook 时保留诊断，不覆盖、不绕过策略，只读发现仍运行。

**首次配置后，请新开 Claude 会话，或重新加载 VS Code 中的 Claude 扩展。** 配置成功只表示磁盘设置就绪，不能保证已经打开的会话立即加载新 Hook。明确 `Stop` 或日志 `end_turn` 才确认完成；普通回答、工具调用、静默均不当作成功。文字已有但终态缺失时等待确认，不先弹问号通知。关闭自动上报仍保留日志发现；若日志不含终态，则无法可靠显示完成。

后台 Agent、Bash 或重新唤醒的代理仍在运行时，前台 Stop 保持任务运行；观察到这些后台工作结束后，还需主代理再次结束回复。子任务通知和代理消息归入当前用户任务，不新建任务。后台等待会持久化，重启后继续；不以固定静默时间或回复措辞猜测完成。

会话释放不能从文件静默推断，远程续问仍保守检查。单条任务文字最多约 64 KiB；存档增长时压缩预览、必要时淘汰最旧已结束发现记录，不修改原始日志。

### 可选 MCP / 状态栏与额外事件

以下步骤不是自动发现或自动完成上报的前提，仅用于记事板 MCP、状态栏额度和额外状态事件。

1. 在 Claude CLI / VS Code 中自行完成登录，使用支持 Hook exec form 的版本（格式核对于 2.1.309）；Windows 可选状态栏包装默认使用 Git Bash。Agent Pet 不代办登录、不读取或展示密钥。
2. 打开“设置 → 智能体与 AI → 可选增强与高级设置”。运行时路径默认自动发现；只有需要指定特定版本时才填写覆盖路径。
3. 如需额度观测，勾选“安装时接入状态栏额度采集”。保留原状态栏输出；没有可信窗口数据时显示不可用、过期或错误，不按 token 使用量估算余额。
4. 点击“预览安装项”，再点击“安装接入”并确认。MCP / 状态栏安装或移除仍需显式确认；不会因普通偏好保存自动安装。已有自动生命周期 Hook 不重复注册。
5. 默认用户配置为 `~/.claude/settings.json` 和 `~/.claude.json`；自定义 `CLAUDE_CONFIG_DIR` 下使用 `settings.json` 与 `.claude.json`。自动生命周期维护不读取或改写 MCP 配置文件。客户端必须共享配置根；项目级或企业策略仍可能禁用 Hook/MCP，不会绕过。
6. 重启 CLI 或重载扩展连接，再在所需会话中提交任务。“已配置”和“运行时已发现”均不代表认证或模型调用已成功。

任务列表同时展示 Codex 与 Claude，沿用各任务的 `sourceLabel`，无法确认 CLI / VS Code 来源时不伪造客户端名称。没有全局任务来源选择开关；自动发现版本不会复用旧的单源或仅 Hook 双源采集服务。

### 独立选择与权限边界

- **默认新建代理**默认 Codex，仅影响之后入队的新任务；队列记录来源后不再随设置改变。既有会话的 `/Sxxxx` 续问/重试按持久化来源路由，旧编号仍属于 Codex。
- **额度展示**同时显示 Codex 与 Claude，一边读取失败不隐藏另一边；不再要求选择单一来源。Claude 展示实际观测的五小时/每周窗口及数据来源，过期、认证失败、缺失不是“剩余 0%”。
- **文本生成**独立选择；旧版保存的来源和模型继续沿用，不因双来源展示而换模型。需要换文本服务时在文本生成区域显式选择。
- Claude SDK 的新建与历史恢复不是原 CLI / VS Code 窗口实时注入。原窗口注入未验证/不支持；只有确认原会话不活跃才允许 SDK 恢复，外部服务或拥有者状态未知时保守拒绝。
- 受控执行默认不开放 shell、网络工具、子代理或绕过审批，只允许经路径边界检查的项目文件操作；这不是 OS 级沙箱承诺。遇到需要额外权限的操作应回到电脑端确认。
- 停止/退出只取消本应用持有的请求并关闭自有采集器，不结束用户的 Claude/Codex/VS Code 进程。退出不是撤销已完成的文件修改。
- Hook 收件箱、采集状态与额度快照在应用管理目录的 `claude/` 中；可能含项目路径和任务文字。不要将这些运行数据提交到仓库或公开分享。

### 移除与异常恢复

关闭“自动确认 Claude 任务完成”会保存停用偏好并安全移除自动管理的五类 Hook，下次启动不会自行加回；日志发现仍保留。可选增强通过“移除接入”并确认来移除，恢复其原状态栏，保留自动生命周期 Hook。两者只删除仍匹配管理记录的自有项，用户改写、同名冲突或 JSON 损坏时拒绝覆盖；请检查诊断及备份，不要重置整份个人配置。

卸载应用前，先关闭自动完成上报，再移除可选增强，并重新加载 Claude。自动生命周期路径由新版启动时安全更新；可选 MCP / 状态栏更换路径仍需从旧路径移除后重新安装。退出桌宠不自动删除 Hook，离线事件可暂存于有界收件箱。

构建将桥接脚本、MCP 入口及运行时依赖置于 `app.asar.unpacked` 的真实路径，保留 Codex 原路径，并固定官方 Claude Agent SDK `0.3.318`；不从配置按钮升级 SDK。

## 桌宠与任务收件箱

每次向 Codex 提交的问题对应一项独立任务，可以同时查看不同项目、不同会话的进度。

- 宠物根据工作、等待输入、完成、失败等状态切换动画。
- 任务完成、失败或中断后保留提醒，可以手动确认。
- 在同一会话继续提问时，之前已结束的提醒自动标记为已读，历史仍保留。
- 其他会话和仍在运行的任务不受自动已读影响。

桌宠支持拖动、位置记忆、惯性甩动和屏幕边缘反弹。更换显示器或调整缩放后，应用会尽量将宠物恢复到可见区域。

右键宠物打开快捷菜单：任务列表、显示/隐藏记事板、今日工作总结为常用入口，设置与退出分别分隔。菜单沿用应用的深浅主题，支持方向键、Home/End、Enter/空格选择，Esc/Tab 或点到其他窗口关闭；靠近屏幕边缘时自动调整位置。菜单关闭后会延迟回收窗口。托盘继续使用系统菜单，快捷菜单加载失败时也会回退到系统菜单。

在“设置 → 宠物 → 显示与尺寸”中控制 **显示桌面宠物**，关闭后仍可从系统托盘操作。宠物库、尺寸、渲染方式、动画和拖动行为也在“宠物”中管理。

在“设置 → 任务与额度 → 点击宠物时显示”中分别选择：

- **显示任务列表**：点击宠物时是否打开任务浮窗。
- **显示额度卡片**：点击宠物时是否打开额度浮窗，支持单独开启。

任务列表和额度卡片可以任意组合；两项全部关闭时点击宠物不弹出浮窗。再次点击宠物或点击其他应用可收起这两类浮窗。选项自动保存，旧配置保留原有显示选择。

记事板位于“设置 → 记事板 → 显示与外观”。开启“显示记事板”后会立即显示并持续悬浮，不随宠物点击、拖动、隐藏或应用焦点变化收起。“记事板始终置顶”默认开启，独立于宠物及任务浮窗的置顶设置。拖动顶部空白区域可调整位置，显示状态及位置会在下次启动时恢复；显示器变化时会调整回可见区域。

点击右上角“−”可收起为圆球，数字表示未完成且未归档的计划数，灵感不计入；超过 99 项显示“99+”，悬停可查看完整数量。拖动圆球调整位置，单击或按 Enter/空格展开，继续原页面和未保存的编辑。收起状态和位置会在下次启动时恢复，收起期间停止读取玻璃背景。右上角“×”仍是隐藏记事板。

玻璃样式收起时仅保留内存中的最后一帧作过渡，展开后由新画面替换，避免闪过普通底色。刚启动还没有缓存时，小球会短暂等待首帧再展开；背景不可用或等待超时会显示半透明备用外观，不影响使用。

“记事板样式”可选择“原有样式”或“液态玻璃”，默认保留原有样式。切换即时生效并自动保存，不重建窗口，也不会丢失正在编辑的草稿。两种样式共用 24px 圆角。Windows 上，液态玻璃读取桌面背景宿主中的当前壁纸画面，按记事板的位置裁切，再由网页绘制模糊、边缘折射、柔光与高光；拖动时取景跟随，Wallpaper Engine 动态壁纸也可更新。此背景不包含普通应用窗口，不使用 Windows 原生毛玻璃。画面仅在内存中处理，不保存截图、不上传、不采集声音；按低帧率请求更新，隐藏、关闭、切回原有样式或使用系统高对比度模式时停止读取。背景源不可用或系统不支持时回退到半透明外观。样式选择仅影响记事板。

即使关闭任务浮窗，仍可通过托盘菜单“打开任务列表”或任务通知手动查看任务；这不会改变已保存的展示选项。设置和日报按需从菜单打开，语音宿主窗口在后台工作。

托盘及宠物右键菜单提供“打开记事板 / 隐藏记事板”，与设置中的开关同步。点击记事板右上角关闭按钮只隐藏记事板，并保存隐藏状态，不影响其他窗口。计划列表不分组，重要项优先，同级按写入时间从新到旧排列。点击标题查看完整事项，正文紧接标题并独立滚动，写入及截止时间以小字固定在窗口底部；点击截止时间可设置或清除：可不设截止、仅选日期，或填写 24 小时制时间。时间留空只保留日期；输入 `16` 自动整理为 `16:00`，输入 `1630` 整理为 `16:30`，也可直接点击常用时间。时间框的清除按钮仅清除时分，面板底部“不设置”同时取消日期与时间。日期选择面板支持切换月份、今天、键盘方向键及 Esc 取消；只有确认后才应用。星号切换重要状态，勾选框切换完成状态。新增和编辑支持独立标题及详细内容，修改内容或截止时间不改变原写入时间及排序。灵感页展示记录来源，并可将想法转为计划。

点击详情右上角的铅笔，在当前页面修改标题与具体事项，底部时间栏保持固定。编辑状态下，重要标记及截止时间也先进入草稿，点击右上角“保存”后统一写入本地文件；“取消”或 Esc 恢复已保存内容，日期面板打开时 Esc 只取消日期选择。返回列表或临时隐藏窗口会保留内存中的草稿，重新进入该计划可继续编辑；未保存的草稿在窗口回收、重载或退出后丢失。保存失败时页面保留草稿并显示错误，可以重试。

勾选完成后，计划仍留在原列表，误勾可以直接取消。点击底部“归档已完成（N）”才会把已完成计划移入“归档”；操作后的提示提供 8 秒撤销入口。归档页按完成时间从新到旧排列，保留完整内容以及写入、截止、完成、归档时间。归档内容只读，点击“移回计划”可恢复到主列表，完成状态保持不变；需要继续做时再取消勾选。归档详情中的删除需要确认，并会永久删除该计划及其备份，不会自动清理旧记录。

每次勾选完成都会保存当时的完整内容快照和完成时间；取消完成会把该次记录标为已撤销，再次完成则新增记录。详情中的“操作记录”可展开查看完成、撤销、编辑和归档等事件，以及每次完成时的标题、事项、重要标记和时间信息。后续修改计划不会改写过去的完成快照。

记事板不依赖数据库，每个计划和灵感保存为独立 JSON 文件，位于应用管理数据目录下的 `notebook/plans/<编号>.json` 与 `notebook/ideas/<编号>.json`。从“设置 → 记事板 → 本地存档”打开实际目录。需要备份时，退出应用后复制整个 `notebook` 文件夹即可。更新文件时保留上一份有效的 `.bak` 备份，主文件损坏且备份有效时会尝试恢复并提示；无法恢复或版本不兼容的文件会保留原件，不会静默覆盖。

首次使用本地存储时列表为空，旧版预览的假数据不会写入存档。已保存内容在重载和重启后保留，尚未接入微信内容同步。

记事板也支持 AI 写入：在「设置 → 记事板 → AI 写入」分别点击「一键连接 Codex」或「一键连接 Claude Code」，两者均直接配置并在页面内反馈结果，MCP 名称统一为 `agent-pet-notebook`，可以同时使用同一份记事板。Codex 按提示重启 MCP 连接；Claude 配置完成后需新开会话或重载扩展，按钮只接入记事板，不安装 Hook 或状态栏。其他 AI 应用通过「其他 AI：复制配置」手动添加本地 STDIO MCP。AI 可以查询、添加和修改计划或灵感。手动新增和编辑仍然可用，AI 保存后窗口自动刷新；原话和修改前后内容会保留，未保存草稿不会被外部更新覆盖。截止时间可选，写入时间自动记录。连接与工具说明见 [记事板 MCP 指南](NOTEBOOK_MCP.md)。

“任务与额度 → 窗口行为”控制宠物、任务列表和额度卡片是否始终置顶。记事板单独设置置顶。界面主题和 Windows 登录后自动启动位于“设置 → 通用”；自动启动选项仅在支持该功能的运行环境中可用。

## 通知与语音

在设置中分别选择需要提醒的任务事件、通知渠道和免打扰时段。

| 渠道 | 功能 |
| --- | --- |
| Windows 系统通知 | 在桌面接收任务提醒 |
| 系统语音 | 使用 Windows 已安装音色播报 |
| GPT-SoVITS | 按需安装本地语音环境，使用自定义模型和参考音频 |
| 个人微信 | 接收任务结果、失败和等待输入提醒 |

GPT-SoVITS 不包含在主安装包中，也不会修改系统 Python、PATH 或 Conda 配置。使用自定义音色时，请导入自己有权使用的模型和参考音频；项目不附带第三方角色音色。

## 微信收发指令

在“设置 → 远程通知”扫码连接微信，按提示完成绑定。开启“发送远程通知”后，可以在手机接收任务提醒；另外开启默认关闭的“指令操作”后，可以从微信继续 Codex 会话或新建任务。

查询会话编号用 `/sessions`，继续会话用 `/S0001 你的要求`。普通聊天消息不会执行任务。电脑需保持联网并运行 Agent Pet。

完整的连接步骤、指令、权限边界、Desktop / SDK 兼容范围和错误处理见 [微信远程指令指南](WEIXIN_REMOTE_CONTROL.md)。

## 自定义宠物

在“设置 → 宠物 → 宠物库”中拖入 ZIP，或点击“导入 ZIP”。导入后使用应用管理的副本，原压缩包可以移动或删除。

支持两种格式：

| 格式 | 包内容 |
| --- | --- |
| Codex 原生精灵表 | 根目录包含 `pet.json` 与 `spritesheet.webp` 或 `spritesheet.png`；支持 v1 的 8×9 和 v2 的 8×11 网格 |
| Agent Pet 状态 GIF | 同一英文前缀的状态文件，例如 `my-pet-idle.gif`、`my-pet-running.gif`，可以只提供已有状态 |

导入器会检查目录结构、路径、图片尺寸和动画帧数。宠物库通过卡片展示预览和名称，点击卡片切换，当前宠物标记为“使用中”。点击某张卡片右上角的“⋯ → 删除宠物”，可以直接删除那一只，无需先切换；删除未使用的宠物不影响当前选择。删除使用中的宠物前，会提示将切换为内置“小团”；内置宠物不可删除。宠物较多时可在卡片区域滚动查看。

宠物库右上角的“下载宠物”可打开下载网站；底部提供“打开目录”和“导入说明”。其他来源的格式不兼容时，展开“导入说明”，点击“复制转换说明”，将说明与素材一起交给 AI 转换后再导入。

## 隐私与数据

- 采集器只读本机 Codex 任务记录，不直接改写原始会话文件。开启指令操作后，通过 Codex Desktop 或 SDK 提交请求，由 Codex 执行并保存。
- 设置、宠物、音色、日报、通知记录及记事板默认保存在本机。
- 微信凭据通过系统安全存储加密，不写入普通设置文件；解除连接时清除。
- 微信通知可选择简略、标准或完整内容级别。
- 远程指令只接受已绑定账号的私聊，经过消息去重、串行队列和高风险指令拦截；需要电脑端审批的操作回到电脑处理。

## AI 连接与模型选择

设置中的 **智能体与 AI → 文本生成**统一控制播报文案和工作日报的文本生成。原有启动、设置变更和失败重试的触发时机保持不变；已有文案与日报缓存继续可用，记录中的模型表示生成当时的模型。任务监控与额度同时包含两个来源，既有任务的远程执行按会话来源路由，不随文本服务切换。

- **沿用既有 AI 来源**：兼容旧版保存的“跟随当前智能体”设置，保持其原先解析出的提供者和模型，不再跟随任务来源选择。
- **Claude Code**：通过官方 Agent SDK 使用已登录环境；与任务的只读自动发现独立，选择后才按文本功能的既有触发时机生成。
- **Codex**：复用本机登录，通过统一运行程序解析选择桌面端 CLI，再读取有效配置和服务端模型列表。业务模块不再直接创建 Codex SDK。
- **DeepSeek / 其他兼容接口**：填写 API 根地址和密钥，通过 `/models` 获取模型，通过 `/chat/completions` 生成 JSON。需要兼容这两个端点及 `json_object` 输出。密钥加密保存在凭据存储中，与地址绑定；更改地址后需重新设置密钥，重定向不转发凭据。

模型选择提供两种方式：

| 选择方式 | 行为 |
| --- | --- |
| 跟随连接默认模型 | 每次新生成前重新读取连接默认模型和模型列表。HTTP 服务未声明默认模型时，需从列表设置“连接默认模型”；不会猜测列表第一项。 |
| 指定模型 | 保留用户选择；模型失效时显示错误并要求重新选择，不自动换模型。 |

设置自动保存。连接或模型选择改变后、设置页面打开时以及新生成前会自动检查连接、认证、默认模型和模型是否可用。模型目录检查通过与实际生成成功分别显示；请求阶段发现运行程序不兼容、接口不兼容、限流、超时或输出无效时，显示相应提示。正在运行的任务固定使用启动时的连接和模型，旧任务不会因设置变化而重新发送到其他服务。

Codex 文本生成使用只读、无需交互的临时会话；文案与日报保存实际连接、模型服务、模型和运行程序版本。生成失败保留原有内置文案和本地日报回退。
