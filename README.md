Agent Pet 是一个面向 AI 编程助手的开源 Windows 桌面宠物。它会跟随 Codex 任务的运行、等待、完成、失败等状态播放不同动画，并通过任务收件箱、系统通知、语音和微信提醒，让你离开电脑后也不会错过任务进展。开启“指令操作”后，还可以从微信向 Codex 发送要求、继续原会话，并在微信接收结果。

当前支持 **Codex Desktop**，并兼容由 Codex TypeScript SDK 驱动的 CC GUI 任务。本文描述 `main` 分支的当前源码；已发布安装包的功能以对应版本的发布说明为准。

## 主要功能

- 🐾 **状态桌宠**：根据任务状态切换待机、运行、等待、完成和失败动画。
- 📥 **任务收件箱**：同时查看多个项目和会话的任务，支持手动确认；同一会话继续提问时，之前已结束的提醒自动标记为已读，历史仍保留。
- 🔔 **多渠道提醒**：支持 Windows 系统通知、语音播报和微信远程通知。
- 🗣️ **可选语音引擎**：可使用 Windows 系统音色，也可按需安装并连接本地 GPT-SoVITS。
- 💬 **微信收发**：扫码连接个人微信，接收任务提醒；开启指令操作后，用 `/Sxxxx` 继续 Codex 会话、用 `/Pxxx` 新建任务。
- 🌙 **免打扰与提醒规则**：分别控制需要提醒的任务状态、通知渠道和安静时段。
- 🎨 **自定义宠物**：支持导入 Codex 原生精灵表宠物包和 Agent Pet 状态 GIF 宠物包，并在宠物库中切换。
- 📝 **每日工作总结**：按项目整理当天完成的任务，支持编辑、复制和重新生成。
- 🔒 **本地优先**：设置、宠物、音色和通知记录保存在本机；敏感连接凭据使用系统安全存储。

## 快速开始

### 1. 下载

前往 [GitHub Releases](https://github.com/wy1003/agent-pet/releases) 下载适合你的 Windows x64 版本：

- `Agent-Pet-Setup-<version>-x64.exe`：推荐的安装版，支持应用内更新。
- `Agent-Pet-Portable-<version>-x64.exe`：免安装便携版，后续版本需要手动下载。

### 2. 启动

运行 Agent Pet 后，它会自动发现当前 Windows 用户下的 Codex 任务。宠物会显示在桌面右侧，也可以通过系统托盘打开任务列表和设置。

在同一会话中继续提问时，之前已结束的任务会自动标记为已读，从宠物提醒列表中移除；其他会话的提醒不受影响，任务历史仍会保留。

### 3. 按需设置提醒

在设置中可以分别开启：

- Windows 系统通知
- Windows 系统语音或 GPT-SoVITS
- 微信远程通知
- 指令操作：允许已绑定微信账号向 Codex 提交任务，默认关闭
- 免打扰时段与紧急提醒

所有设置都会自动保存在本机，覆盖安装新版本不会删除现有设置、微信连接、宠物、音色或通知记录。

## 功能说明

### 桌宠与任务收件箱

每次向 Codex 提交的问题都会作为一项独立任务显示。任务运行时可以看到当前阶段；任务完成、失败或中断后会保留提醒，直到你手动确认，或在同一会话中继续提问。自动已读只影响该会话中已经结束的任务，历史记录仍可查看。

宠物支持拖动、位置记忆、惯性甩动和屏幕边缘反弹。多屏幕或系统缩放变化后，应用会尽量将宠物恢复到可见区域。

### 微信通知与远程指令

在“设置 → 远程通知”中连接微信：

1. 使用手机微信扫描二维码。
2. 如微信要求验证，在 Agent Pet 中输入手机显示的数字验证码。
3. 扫码确认后，在微信中向 Agent Pet 发送任意一条绑定消息。
4. Agent Pet 明确显示“微信已连接”后，即可接收任务提醒。

登录凭据经系统安全存储加密后保存在本机，解除连接时会一并清除。

#### 实验性远程指令操作

“指令操作”是 Agent Pet 的全局开关，默认关闭，并且和“发送远程通知”相互独立。当前已实现的渠道是个人微信；QQ、飞书属于后续适配计划。开启后，所有 Agent Pet 已识别的本机项目都可通过项目 / 会话编号访问，无需为每个项目单独配置白名单。

保持电脑联网，运行 Agent Pet，并先在 Codex 完成登录。在“设置 → 远程通知”开启“指令操作”，向已绑定的 Agent Pet 发送 `/sessions` 获取真实会话编号，再发送 `/S0001 只回复收到`（将 `S0001` 替换为查询到的编号）。Windows 上由桌面端持有的会话会直接交给 Codex Desktop 执行，消息和回复会显示在原会话中，结果也会返回微信。2026-10-20 已完成这条微信续问链路的实机验证。

普通聊天消息不会执行任务：首次绑定或连接恢复后的第一条普通消息会返回一次简短引导；发送“帮助”“指令”“怎么用”或 `help` 会返回完整指令集；看起来像会话编号但漏写 `/` 时只会提示正确格式。其余不以 `/` 开头的消息仅静默刷新远程连接上下文，不会交给 Codex。所有会执行任务的远程指令都必须以半角 `/` 开头，例如：

标准任务通知会包含适合手机阅读的结果摘要，并在底部给出可复制的跨渠道续问格式：“继续处理此任务：`/S0001 你的要求`”。这些编号不依赖各平台的引用能力：

```text
/help
/projects
/sessions
/sessions P001
/S0001 请补充测试
/S0001 状态
/S0001 停止
/S0001 重试
/P001 新任务：检查今天的构建结果
```

`/help` 返回完整指令帮助，`/projects` 列出电脑端已识别的项目，`/sessions [P001]` 列出最近的会话。直接在 Codex 中创建的无项目会话会显示为“普通对话”，不会混入项目列表，但仍可通过 `/S0001` 继续处理。`/S0001` 是本机稳定且全局唯一的会话指令，Agent Pet 会据此反查项目和真实 Codex 会话；`/P001` 用于在指定项目中新建任务。旧 `/Cxxxx` 指令仅作为兼容格式继续识别，新通知和帮助不再使用该前缀。查询结果不会暴露本机路径或真实 Codex 会话 ID。

“已接收”表示指令进入 Agent Pet 队列，尚未确认送达 Codex。正常完成后会返回“已完成”和结果摘要。若返回“执行状态待确认”，请先在电脑端检查，避免重复发送。已开始执行的请求遇到模型超时时，会提供 `/S0001 重试`；恢复前会检查已有结果。

Windows 上继续桌面端已打开的会话时，Agent Pet 通过本机 IPC 将请求交给持有该会话的 Codex Desktop 执行，避免另起进程争抢写入锁。结果按返回的轮次 ID 从本地日志确认，“停止”也仅针对该轮次。提交结果不确定时不会自动重发或切换到 SDK，需先在电脑端检查。此通道适配 Desktop 26.1013 的本地 follower 协议；协议不匹配时会报告错误。

未找到桌面端会话持有者以及新建任务时，使用 SDK；优先选用本机 Codex Desktop 内核，避免内置旧内核漏读新版历史，未找到时再使用内置版本或 PATH 中的 Codex。SDK 路径产生的轮次可能需要重新打开 Desktop 会话才能显示。可通过 `AGENT_PET_CODEX_EXECUTABLE` 指定 SDK 内核路径。最近一次调用的路由、轮次 ID、内核路径或失败分类保存在数据目录的 `remote-control/last-execution-diagnostic.json`，不保存请求正文或凭据。

完整的连接步骤、状态说明、兼容范围和故障处理见 [微信远程指令指南](docs/WEIXIN_REMOTE_CONTROL.md)。

引用消息只作为路由校验的兼容信息；用户发送的内容仍必须以 `/` 开头。会话指令和引用映射冲突时会拒绝执行，不会猜测目标。相同会话的多条要求会串行执行，避免上下文交叉。

远程任务核心不依赖微信字段：Agent Pet 内部只处理统一的渠道消息、项目 / 会话路由和安全策略，微信由独立适配器负责协议转换。以后增加 QQ、飞书等渠道时，只需实现对应适配器；不同渠道的消息标识、授权和投递队列相互隔离。

该功能不是任意远程终端：只接受已连接渠道中受信任账号的私聊指令，并会拒绝发布、对外发送、安装卸载、不可逆删除、提权等高风险请求。需要审批或更高权限的操作必须回到电脑端确认。“停止”只能停止由 Agent Pet 发起且仍在执行的远程轮次，不能终止直接在 Codex Desktop 中启动的任务。

### 语音播报

Agent Pet 可以直接使用 Windows 已安装的系统音色。需要更自然或自定义的声音时，可以在语音设置中按需安装本地 GPT-SoVITS 运行环境，并导入自己有权使用的模型与参考音频。

GPT-SoVITS 不会打进 Agent Pet 主安装包，也不会修改系统 Python、PATH 或 Conda 配置。项目不附带或分发第三方角色音色。

### 自定义宠物

在“设置 → 外观与启动 → 宠物库”中拖入或选择宠物 ZIP。支持两种格式：

- **Codex 原生精灵表**：根目录包含 `pet.json` 与 `spritesheet.webp` 或 `spritesheet.png`。支持 8×9 的 v1 和 8×11 的 v2 精灵表。
- **Agent Pet 状态 GIF**：包含同一英文前缀的标准状态 GIF，可以只提供需要的状态，例如：

```text
my-pet-idle.gif
my-pet-running.gif
my-pet-failed.gif
```

Agent Pet 会在导入前检查文件结构、安全路径、精灵表版本与尺寸，或 GIF 的画布尺寸和动画帧数。导入后使用的是应用管理的副本，原 ZIP 可以移动或删除。

宠物库提供下载网站入口，以及“复制转换说明”按钮。其他来源的格式不兼容时，可以把素材和转换说明一起交给 AI 转换，再导入生成的 ZIP。

## 隐私与安全

- 任务采集器只读本机 Codex 任务记录，不直接改写原始会话文件。开启指令操作后，Agent Pet 会通过 Codex Desktop 或 SDK 提交用户请求，由 Codex 执行并保存会话。
- 设置、宠物、音色、日报和通知记录默认保存在本机用户数据目录。
- 微信连接凭据使用 Electron `safeStorage` 调用操作系统能力加密，不会写入普通设置文件。
- 微信通知内容可以选择简略、标准或完整级别。
- 实验性远程指令操作默认关闭；开启后仍只接受已连接渠道中受信任账号的私聊指令，并受消息去重、串行队列和高风险操作拦截保护。
- 项目 / 会话编号及路由映射保存在本机；微信消息不能绕过电脑端审批，也不会获得任意命令执行能力。
